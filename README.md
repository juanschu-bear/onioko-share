# onioko-share

Private share pages from ONIOKO. Static files, deployed on Vercel.

- `/hookd` : page for Bastian (HOOKD)
- `/next-generation` : landing page for business families (handover to the next generation)
- Every page is `noindex` (meta tag, `X-Robots-Tag` header, `robots.txt`).
- The root path redirects to https://onioko.com.
